Kun painetaan **Yes**, main-funktio löytyi:

```bash
undefined8 main(void)

{
  int iVar1;
  char local_28 [32];
  
  puts("What\'s the password?");
  __isoc99_scanf(&DAT_0010201d,local_28);
  iVar1 = strcmp(local_28,"piilos-AnAnAs");

```
<br>

Kuten tulosteesta voidaan nähdä, muuttujien nimet ovat Ghidrassa melko epäselviä, eikä näkyvillä oleva kieli vastaa suoraan alkuperäistä C-kieltä. Tässä tehtävässä täytyy tehdä oma valistunut arvio siitä, millaisia muuttujanimet ovat voineet olla ja mitä C-kielen funktiokutsuja ohjelmassa on käytetty.

Aluksi erityisesti **&DAT_0010201d** vaikutti sellaiselta tiedolta, josta ei saisi puristettua irti yhtään mitään. Tutkimalla binääriä kuitenkin tarkemmin huomasin, että Ghidra antaa suoraan merkit ASCII-muodossa ja vielä "selkokielisinäkin":

**%19s** siis kertoo scanf-funktiolle, että syöte luetaan merkkijonona ja että syötteestä hyväksytään enintään 19 merkkiä. Miksi 19, kun tilaa on varattu kuitenkin 32 merkille? Tämä on todennäköisesti ohjelmoijan omaa tajunnanvirtaa, jota edes Ghidralla ei pystytä takaisinmallintamaan. Loput koodista arvioin toimivan seuraavanlaisesti:

```bash
#include <stdio.h>
#include <string.h>

int main(void)

{
  int password;
  char input [32];
  
  printf("What\'s the password?");
  scanf("%19"s,input);
  password = strcmp(input,"piilos-AnAnAs");
  if (password == 0) {
    printf("Yes! That\'s the password. FLAG{Tero-0e3bed0a89d8851da933c64fefad4ff2}");
  }
  else {
    printf("Sorry, no bonus.");
  }
  return 0;
}
```

<br>

Toimintaperiaate on seuraavanlainen: ohjelma pyytää salasanaa, lukee syötteen scanf-funktiolla ja vertaa sitä merkkijonoon **piilos-AnAnAs** käyttäen strcmp-funktiota. Funktio palauttaa arvon 0, jos merkkijonot ovat identtiset ja tulostaa lipun. Jos merkkijonot eroavat toisistaan, funktio palauttaa jonkin muun arvon ja ohjelma tulostaa virheilmoituksen. Kirjastot **stdio.h** ja **string.h** oli selvitettävä sen perusteella, mitä ohjelmassa käytetyt funktiot tekevät. Scanf ja printf tarvitsevat toimiakseen stdio.h-kirjaston (Cppreference.com, stdio.h), kun taas strcmp käyttää string.h-kirjastoa (Cppreference.com, string.h). Jos vielä haluaa selvittää Ghidran avulla yleisesti, että mitkä funktiot vaativat kirjastoja toimiakseen, nämä yleensä näkyvät binääritulosteessa **<EXTERNAL>**-muotoisina.

## c) If backwards

Tällä kertaa tarkoituksena on takaisinmallintaa myös h3-tehtävässä läpikäyty **passtr**-ohjelma Ghidralla ja muuttaa tämän toimintaa niin, että ohjelma hyväksyy kaikki muut syötteet paitsi siihen kovakoodatun salasanan. 
Toistetaan siis Ghidralla samat toimenpiteet kuin packd-tiedostonkin kanssa ja analysoidaan se. Samalla tavoin saimme main-funktion pseudo-C-kielellä: 

```bash
undefined8 main(void)

{
  int iVar1;
  char local_28 [32];
  
  puts("What\'s the password?");
  __isoc99_scanf(&DAT_0010201d,local_28);
  iVar1 = strcmp(local_28,"sala-hakkeri-321");
  if (iVar1 == 0) {
    puts("Yes! That\'s the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3b1}");
  }
  else {
    puts("Sorry, no bonus.");
  }
  return 0;
}
```
<br>

Muutetaan taas koodi oikeaksi C-kieleksi, jonka jälkeen on helpompi lähteä muokkaamaan salasanan hyväksyntää käänteiseksi. Aluksi olin lähdössä merta edemmäs kalaan ja pohdin monimutkaisempia ratkaisuja kuin näin jälkikäteen ajatellen olisi ollut tarpeen. Yksinkertaisin ratkaisu olikin kääntää ehtolause päälaelleen. Kuten Murphyn sodankäynnin laissakin todetaan: "Jos se on tyhmää, mutta se toimii, se ei ole tyhmää" (Meyer). Käytin **nano**a koodin muokkaamiseen ja sain aikaan seuraavanlaisen lopputuloksen:

```bash
#include <stdio.h>
#include <string.h>

int main(void)

{
  int password;
  char input [32];
  
  printf("What\'s the password? ");
  scanf("%19s", input);
  password = strcmp(input,"sala-hakkeri-321");
  if (password == 0) {
    printf("Sorry, no bonus.");
  }
  else {
    puts("Yes! That\'s the password. FLAG{Tero-d75ee66af0a68663f15539ec0f46e3");
  }
  return 0;
}
```

<br>

Tallensin tiedoston **passtr1.c**-nimellä ja käytin **gcc**:tä muuttaakseni ohjelman suoritettavaan muotoon:

```bash
gcc passtr1.c -o passtr1
```

```bash
#include <stdio.h>
#include <string.h>

int main(int argumentCount, char *arguments[]) // Argumenttien määrä ja taulukko, joka sisältää annetut argumentit

{
  int comparison;
  int returnValue;
  size_t pwLength;
  
  if (argumentCount == 2) {               // Tarkistaa, että ohjelmalle on annettu yksi argumentti (2 johtuu siitä, että ohjelman nimi lasketaan mukaan)
    pwLength = strlen("password1");       // Laskee merkkijonon "password1" pituuden
    comparison = strncmp(arguments[1], "password1", pwLength); // Vertaa annettua syötettä salasanaan "password1".
    if (comparison == 0) {               // 0 meinaa, että syöte täsmää
      printf("Yes, %s is correct!\n", arguments[1]); // %s korvataan argumentin sisällöllä
      returnValue = 0;                  // Onnistunut palautusarvo
    }
    else {
      printf("No, %s is not correct.\n", arguments[1]);
      returnValue = 1;                  // Virheellinen palautusarvo
    }
  }
  else {
    printf("Need exactly one argument.");    
    returnValue = 0xffffffff;
  }
  return returnValue;
```

Tämä tehtävä oli mielestäni huomattavasti vaikeampi kuin ensimmäinen. Ghidrasta saatu koodi sisälsi useita kohtia, joiden tarkoitus ei ollut kovinkaan selvä, ja erityisesti argumenttien käsittely vaati runsaasti selvittelyä, koska - kuten olen aiemminkin todennut - C-kieli ei kuulu vahvuuksiini. Olen hyödyntänyt tätä tehdessä myös tekoälyä (Copilot) jonkin verran, mutta lähinnä vain selittämään minulle tiettyjen funktioiden ja muuttujien merkityksiä. 

Lopuksi äärimmäisen yksinkertaistettu yhteenveto ohjelman toiminnasta on, että se vertailee käyttäjän antamaa komentoriviargumenttia merkkijonoon "password1" ja hyväksyy tai hylkää sen vertailun tuloksen perusteella. #include <string.h>
