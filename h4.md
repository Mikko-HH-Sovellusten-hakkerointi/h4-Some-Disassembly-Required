## a) Asenna Ghidra

**Ghidra** on Yhdysvaltain Kansallisen turvallisuusviraston (NSA) alun perin kehittämä takaisinmallinnustyökalu, joka on myöhemmin julkaistu avoimella lähdekoodilla (Newman 2019). Nimensä mukaisesti, tämä tehtävä aloitetaan asentamalla kyseinen ohjelma omalle virtuaalikoneelle: 

```bash
sudo apt install ghidra
```

Tarvittavat Java-kirjastot löytyivät ainakin Kalista jo valmiina, joten näitä ei tarvinnut lähteä erikseen asentelemaan. Ghidran voi siis suoraan vain asennuksen jälkeen käynnistää komennolla ```ghidra```:
